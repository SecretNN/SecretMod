# SecretMod
## Мод для minecraft (1.21.1 neoforge), что бы вы могли Показывать гифки с моего сайта https://secretnn.pythonanywhere.com/
#### Что бы вы могли использовать гиф (который появится над вашей головой) Вам надо по умолчанию нажать на G, в настройках клавишу можно поменять
#### Что бы другие видели гиф они должны также иметь данный мод
#### Гифки в списке обновляются как только вы заходите снова в этот меню, не нужно перезагружать майнкрафт, можете прямо во время игры загружать гиф и через несколько секунд уже использовать в майнкарфте!
